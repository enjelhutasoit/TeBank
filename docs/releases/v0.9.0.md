## Architecture decisions

- Retain reviewed details in per-intent JSON files using the existing checkpoint format.
- Use intent UUIDs as the history keys so repeated recipient and amount combinations remain distinct.
- Display stable recipient ordering with UUID tie-breaking. Archived reviews lack transaction timestamps.
- Reuse the durable submission journal and simulated bank receipt for read-only status lookup.

The history contains archived demo transfers. The active transfer remains accessible through **Transfer lokal**. Earlier reviews discarded before this version may lack recipient information. The simulated bank models acceptance, and the sample dashboard balance retains its synthetic values.
