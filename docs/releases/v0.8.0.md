## Demonstration

Approve a synthetic business, enter a demo transfer, enable **Simulasikan respons hilang**, review and confirm. Once **Hasil belum diketahui** appears, terminate and relaunch TeBank. Unlock, reopen the approved dashboard, and select **Transfer lokal**. The same recipient should appear with **Diterima untuk diproses**.

## Scope

The single active review uses a local checkpoint; the SDK journal stores submission identity and a second SQLite store represents the simulated bank receipt. A review without a journal entry requires explicit confirmation. A journal entry with no matching receipt stays pending. The simulator represents acceptance for processing only. Real bank integration, settlement and multi-transfer history are outside this milestone.
