# v0.5.0 — Slice A (unreleased)

This milestone hardens the existing synthetic onboarding and dashboard demo for an interview walkthrough.

- The dashboard exposes the transaction direction and nominal amount in its accessibility label, for example “Keluar, 425.000 rupiah”.
- Simulator coverage exercises the approval-to-detail flow and checks the accessibility labels for credit and debit transactions.
- The walkthrough demonstrates how a request can recover after a lost response using the original request ID.

See the [walkthrough and verification record](../slice-a-demo.md) for the tested environments, outstanding device checks and profiling procedure. Final release verification requires a successful `./verify.sh` run on the maintainer’s Mac against the intended release revision.
